# JavaScript To-Do List App

Responsive client-side task manager built with HTML, CSS and vanilla JavaScript.

## Features
- Create, read, edit and delete tasks
- Mark tasks complete or active
- Filter by All, Active and Completed
- Automatically save tasks to `localStorage`
- Dynamic DOM rendering and delegated event listeners
- Responsive on mobile and desktop

## Run
Open `index.html` in a modern browser.

## Publish on GitHub Pages
Upload `index.html`, `style.css` and `script.js` to the root of your repository, commit changes, then enable GitHub Pages in Settings → Pages. README is optional.
